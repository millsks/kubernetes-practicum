How this course works

1 · Read and try

Lessons mix explanation, diagrams, and step-through visualizers with runnable Python cells that use kubelab, a small library that reads manifests and reasons about them the way the control plane does.

2 · Practice

Graded exercises in every module check your code in the page, with hints and a reference answer for the small in-page tasks.

3 · Build in labs

Each module ends with labs on your Mac: pixi run start m02-lab1, write the manifest or tool, then pixi run grade m02-lab1.

4 · No answer key

Labs ship without solutions. Their checks are the specification, and CI proves every untouched starter fails, so a green grade means you built it.

5 · Run it for real

Offline checks run in seconds. Optional live checks (pixi run grade-live <lab>) apply your work to your kind cluster and wait for it to be healthy.

6 · All local

Everything runs on a MacBook: Colima for the Linux VM, kind for a three-node cluster, and Pixi for pinned tools. No cloud account needed.
