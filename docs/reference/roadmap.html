Roadmap

The practicum goes from your first Pod to a platform deployed entirely from Git. Stage 1 is available now. Each later stage arrives as its own release, with the same mix of lessons, graded exercises, labs without solutions, and quizzes.

Stage 1 · Foundations (available)

  • M00 Your Mac Lab: Colima, kind, Docker vs containerd, the primer cluster
  • M01 How Kubernetes Thinks: architecture, objects, reconciliation, kubectl
  • M02 Pods: lifecycle, probes, resources and QoS, sidecars, security, debugging
  • M03 Deployments and Workloads: selectors, rollouts, rollbacks, Jobs and CronJobs

Stage 2 · Networking and state (next)

  • M04 Services, DNS, and cluster networking: ClusterIP, NodePort, headless Services, EndpointSlices, kube-proxy
  • M05 Gateway API with Traefik: GatewayClass, Gateway, HTTPRoute, weighted canaries, reading old Ingress objects (the community Ingress NGINX controller was retired in March 2026)
  • M06 ConfigMaps and Secrets: env vs files, live reload, what base64 doesn't protect, Sealed Secrets
  • M07 Storage: PersistentVolumes, claims, StorageClasses, StatefulSets with PostgreSQL

Stage 3 · Packaging and scaling

  • M08 Helm 4: charts, templates, values, releases, umbrella charts, OCI registries
  • M09 Resources and autoscaling: metrics-server, HPA behaviour, VPA, KEDA
  • M10 Scheduling and clusters: affinity, taints, topology spread, PodDisruptionBudgets, quotas, contexts

Stage 4 · Production

  • M11 Security: RBAC, Pod Security Admission, NetworkPolicies
  • M12 Observability and troubleshooting: Prometheus, Grafana, ServiceMonitors, the debugging tree
  • M13 GitOps with Argo CD: Applications, sync policies, app-of-apps, sync waves, ApplicationSets, drift

Capstone · A GitOps-run notes platform

A web frontend, a FastAPI service, PostgreSQL, and Redis, packaged as an umbrella Helm chart, exposed through Gateway API, with autoscaling, NetworkPolicies, and Prometheus metrics. Argo CD deploys every component, platform and app, from your own Git repository, so a commit is a deploy. Graded with offline chart checks and optional live checks on the primer cluster.
