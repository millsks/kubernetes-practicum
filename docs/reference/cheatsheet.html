kubectl

TaskCommand
Which cluster am I on?kubectl config current-context · kubectl config use-context kind-primer
Everything, everywherekubectl get all -A · kubectl get pods -A -o wide
The whole object / one fieldkubectl get deploy web -o yaml · -o jsonpath='{.status.readyReplicas}'

Why is it like this?kubectl describe pod POD · kubectl get events --sort-by=.lastTimestamp

Rollouts

TaskCommand
New imagekubectl set image deploy/web app=IMAGE:TAG
Progresskubectl rollout status deploy/web
History and undokubectl rollout history deploy/web · kubectl rollout undo deploy/web [--to-revision=N]
Pause, resume, restartkubectl rollout pause|resume|restart deploy/web
Scalekubectl scale deploy/web --replicas=6
Run a CronJob nowkubectl create job once --from=cronjob/NAME

Bounds: total ≤ replicas + maxSurge (percent rounds up); ready ≥ replicas − maxUnavailable (percent rounds down).
